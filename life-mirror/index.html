PERSONAL APPLICATION

RIKI-LIFE-GENERAL

A personal life mirror: a private, single-operator workspace for organizing information, correspondence, files, and schedules.

This is an owner-operated personal tool, not a public service. This website provides app information only; it does not sign visitors in or display the operator's Google data.

What the app does

The app connects to Google services with the account holder's consent. It can retrieve information for personal reference and perform actions the operator explicitly requests:

  • Gmail: read messages and mailbox information; create drafts and send messages when instructed.
  • Google Drive: read and organize files, and create, update, move, or delete files when instructed.
  • Google Calendar: read calendars and manage events and reminders when instructed.

Access and control

Google authorization is handled by Google. The operator can revoke the app's access through Google Account connections. Previously saved copies must be managed separately, as described in the privacy policy.
